# Aysha's Birthday Website 💗 — Render-ready bundle

## Important: keep the folder structure
Upload the **contents of this ZIP**, not the ZIP file itself. `index.html`, `style.css`, `script.js`, and the `assets` folder must all be together at the repository root. The `assets` folder must directly contain all nine `aysha-*.jpg` photos, `darkhaast-cover.jpg`, `darkhaast.mp3`, and `background-animation.mp4`.

Expected GitHub repository layout:

```
index.html
style.css
script.js
assets/
  aysha-01.jpg ... aysha-09.jpg
  darkhaast-cover.jpg
  darkhaast.mp3
  background-animation.mp4
```

## Render Static Site settings
- Root Directory: leave blank
- Build Command: leave blank
- Publish Directory: `.`

After committing the extracted website files to GitHub, connect that repository in Render as a **Static Site** and deploy it. If a service already exists, confirm the Publish Directory is `.` and use **Manual Deploy → Deploy latest commit**.

## Music
Browsers commonly block autoplay with sound. The song starts after the visitor taps the page or presses the round play button. The player shows a status if the MP3 cannot be loaded. Make sure `assets/darkhaast.mp3` was uploaded too.

## Background video
`assets/background-animation.mp4` plays muted, loops, and stays behind the page content.

## Included content
- All nine photos in the gallery, including the clearer replacement photo.
- Four scrapbook photo cards.
- Darkhaast music player and cover image.
- Silent looping background animation.
- Animated age reveal, birthday countdown, scrapbook, and final birthday message.
